Download the universal ZIP, unpack it, and drag **SmartDisk.app** into
**Applications**. Requires **macOS 26+**, on Intel or Apple silicon.
No account, Rust, Xcode, Homebrew or FUSE installation is needed.

This community build is **not Apple-notarized**. If macOS blocks the first
launch, follow the English **READ ME FIRST.txt** inside the ZIP. Only approve
downloads from a source you trust; do not disable Gatekeeper.

Smart Disk now asks you to choose source folders before indexing. Its English
interface includes smart folders, file previews, text search and privacy
settings. Recognised identity documents are hidden across search and the drive
until enabled. Removing a source revokes its indexed results, and disabling
document text storage clears existing active text records.

All indexing runs locally. Your originals stay in place; editing a file through
a smart folder edits its original. Files saved onto the drive go to Slim Inbox.
